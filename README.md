# 💊 FarmaControl Pro

**Herramienta web para conciliación y arqueo de caja farmacéutica (CLP).**

> 🌐 **[PRUEBAR DEMO EN VIVO →](https://paonsaphir.github.io/Money-Pharma/)**
> *(Abre en el navegador, sin instalar nada.)*

![Captura de pantalla](captura.png)

---

## ✨ Características

- 🧮 **Conciliación de caja** automática con cálculo de diferencias.
- 📦 **Arqueo** de billetes y monedas por denominación (CLP).
- 💵 **Soporte completo de pesos chilenos** (formato y redondeo correctos).
- 📤 **Exportación** de resultados (PDF / Excel) para registro.
- 🖥️ **100% offline**: un solo archivo HTML, funciona sin internet.

## 🚀 Cómo usar

### Opción A (recomendada): Demo en vivo
Abre el enlace de arriba. No necesitas descargar ni instalar nada.

### Opción B: Descarga
1. Descarga `index.html` (botón **Code → Download ZIP**).
2. Ábrelo con doble clic en cualquier navegador (Chrome, Firefox, Edge).

## 🛠️ Tecnologías

- HTML5 + CSS + JavaScript puro (sin frameworks, sin build).
- Moneda: CLP (peso chileno).
